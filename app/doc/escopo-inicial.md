# Escopo inicial do projeto

> **DOCUMENTO OBSOLETO** — revisado em 2026-05-25.
>
> Este documento descreve o escopo original pensado antes do início do desenvolvimento.
> O projeto evoluiu para um agente de automação de formulários focado (sem backend web,
> frontend ou multiusuário). O estado atual e a documentação vigente estão em:
> - `README.md` — visão geral, pipeline e instruções de uso
> - `todo.md` — histórico de fases e pendências ativas
> - `Cronograma do projeto.md` — estimativas e entregas por fase

## Objetivo
Criar uma aplicação de IA com arquitetura modular, permitindo trocar o LLM facilmente e evoluir para agentes especializados.

## Primeira entrega
Construir um MVP funcional com:
- Backend
- Frontend simples
- Integração inicial com LLM
- Estrutura de agentes
- Persistência básica
- Logs
- Configuração por ambiente

## Fora do escopo neste primeiro momento
- Treinamento de modelo próprio
- Fine-tuning
- Autenticação complexa
- Dashboard avançado
- Deploy em produção
- Multiusuário robusto
