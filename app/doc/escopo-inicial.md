# Escopo inicial do projeto

## Objetivo
Criar uma aplicação de IA com arquitetura modular, permitindo trocar o LLM facilmente e evoluir para agentes especializados.

## Primeira entrega
Construir um MVP funcional com:
- Backend
- Frontend simples
- Integração inicial com LLM
- Estrutura de agentes
- Persistência básica
- Logs
- Configuração por ambiente

## Fora do escopo neste primeiro momento
- Treinamento de modelo próprio
- Fine-tuning
- Autenticação complexa
- Dashboard avançado
- Deploy em produção
- Multiusuário robusto
